📊 INDIA GENERAL ELECTION RESULT ANALYSIS 2024
🗳️ Power BI • SQL • Data Modeling • Analytics

This project provides an interactive and insightful analysis of the India General Elections 2024 using Microsoft Power BI, MySQL, and Advanced Data Modeling techniques.
It helps stakeholders explore state-wise results, party performance, constituency insights, and voting behavior trends.

🔍 Project Objectives

Build an end-to-end analytical dashboard for GE 2024
Leverage SQL for data transformation, cleaning, and KPI extraction
Create a star-schema data model using Power BI relationships
Visualize election outcomes with dynamic filtering and drill-downs
Provide decision-support insights for political analysis and research

🏗️ Data Modeling Approach

A well-structured Entity Relationship Diagram (ERD) / Schema was designed to ensure optimized performance and accurate visuals.

✔️ Tables Used:

partywise_results
constituencywise_results
constituencywise_details
statewise_results
states

🔗 Relationships:

Party ID connects party-level performance to constituency results
Constituency ID links candidate-level votes
State ID enables state filtering across visuals
ERD visualization is included in the repository as an image.
